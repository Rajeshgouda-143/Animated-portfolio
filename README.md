# ✨ Animated Portfolio — Creative Developer Portfolio

A modern and interactive personal portfolio website designed to showcase my skills, projects, and journey as a developer. This project combines creative animations with a clean user interface to create an engaging browsing experience.

🔗 **Live Demo:** [Explore My Animated Portfolio](https://animated-portfolio-seven-alpha.vercel.app/)

## 🎨 Features

- ✨ **Animated UI** — Smooth visual effects and engaging transitions.
- 👨‍💻 **About Me** — Introduction to my background and development journey.
- 🛠️ **Skills Showcase** — Highlights my technical skills and technologies.
- 🚀 **Projects Section** — Showcases my development projects.
- 📩 **Contact Section** — Provides a way for visitors to connect with me.
